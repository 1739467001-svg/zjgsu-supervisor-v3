# 本地上线整改验收记录（2026-10-05）

本次为本地候选版本整改与 GitHub 同步，不是生产部署完成证明。没有访问或修改云服务器，没有导入正式课表，没有更改生产账号或历史评价。

## 已实现

- 密码采用带随机盐的 scrypt 哈希；旧密码在成功登录时逐账号升级，工号默认密码强制修改。
- 临时密码必须修改；密码变更和停用账号使旧会话失效。旧版本会话不再兼容，发布后所有用户需重新登录。会话密钥少于 32 字符时拒绝签发。
- 登录尝试限流（进程内计数；多实例及反向代理场景仍需专项配置与验证）。
- 管理员可新增、重置、停用、重新启用账号；停用保留历史记录。角色、附加角色、学院与督导范围一次性提交；拒绝管理者移除自己的全部管理权限。
- 正式提交评价需完整评分与评语；验证听课日期、周次、课程排课范围以及计划作者、课程、学期关联。提交评价不再误完成其他周次的计划。
- 课程详情、教师筛选、已用周次等入口补充学院范围检查。
- 课表分 MBA/非 MBA 入口：先预览，再确认导入。预览绑定文件、账号、学期和数据库快照，10 分钟失效。
- 已关联计划或评价的课程不允许覆盖；未出现在上传文件中的课程保留；写入使用事务。新建计划和评价同步锁定学期、课程，阻止导入期间产生未受保护的关联。
- 原一键初始化部署脚本检测到已有项目或配置即停止，不允许被误用为生产代码更新工具。

- 类型检查通过，生产构建通过。
- 25 个测试文件通过：286 项通过、2 项跳过。
