# 换学期与课表导入操作手册

更新：2026-10-07。本文取代旧版的9月7日起算、命令行写入和删除未上传课程说明。生产数据库迁移、历史恢复与代码更新是独立操作，不自动串联执行。

## 查看学期与启用学期

页面上方“查看学期”下拉框可选择 `2025-2026-2`、`2026-2027-1`，显示对应课程、评价、计划和统计。历史档案只读，可查询和导出。查看学期不改变全校当前学期、不删除历史、不重置评价。

只有全校管理人员在“学期管理”中才能创建、启用学期。启用前先核对日期及资料，旧学期记录继续保留。新学期的评价从零开始，不能复制旧评价充数。尚未明确归属的历史记录不得按听课日期猜测学期，须保留原件并逐项核查课程关联。

**浙江工商大学2026年秋季第一周从2026-09-14（周一）开始，共18周。** 学校确认的起点优先于原课表最早日期；不能为了消除第0周警告把起点改成9月7日。

## 网页正式导入

1. 研究生院主管或技术管理员完成初始改密后，打开“上传课程数据”。学院秘书和学院领导无上传权限。
2. 核对当前目标学期、第一周日期和总周数。历史学期不开放导入。
3. 分别使用“非MBA课表”“MBA课表”入口上传原始Excel；两种格式由现有解析器识别，格式不一致拒绝。
4. 先预览，检查新增、更新、未变化、受保护冲突、学院分布及解析警告。**预览不写入数据库。**
5. 核对无误后确认导入。文件、学期、账号授权/密码、学期配置、课程或关联计划/评价快照变化，以及令牌超过10分钟，均需重新预览。
6. 导入后查看课程列表和统计。以实际解析及数据库为准，不修改业务记录去匹配参考数。

所有写入在事务内；并发首次导入串行校验，第二个旧预览失效。部分批次失败整批回滚。重复相同文件不新增重复课程，ID与内容保持稳定。已关联计划或评价的课程不允许覆盖；有冲突时整批停止，先核查原记录。未出现在上传文件中的课程保留，历史课程不被此次上传改动。

## 只读本地预检

命令行仅用于查看解析结果，不连接数据库；`--apply`、`--activate`等写入参数已禁用。

```bash
pnpm exec tsx scripts/import-courses.ts "非MBA原课表.xls" "MBA原课表.xls" \
  --semester 2026-2027/第一学期 --start-date 2026-09-14 --weeks 18
```

现有解析器按表头识别。MBA按“班级、课程、教师、星期、时间、教室”归并日期并换算周次；考试场次不作为听课课程；班级、课程、教师等内容来自原表。MBA原表没有校区列，现有规则填“教工路”，学生专业留空。非MBA合写院名按已确认口径归为工商管理学院，MBA归MBA学院，历史学院名称不重写。

本轮两份指定原表：非MBA1498行；MBA817行归并379条后进一步合并为354门；合计1832门、24学院，仅为这两份文件的验收结果。新文件不得强求同样数量。

MBA原表有45场9月12/13日授课，按学校起点为第0周；4场缺教师。原Excel和警告必须保留，不移日期、不补造教师。16门归并课程无有效周次，服务端禁止创建计划或评分。对异常场次的最终业务处理待研究生院确认或修订原课表。

## 人员与历史恢复

通讯录使用既有 `scripts/import-users.ts` 解析器，按工号合并，预检100唯一人员、26双身份（傅培华+25学院领导），不增加其他双身份。只读预检后，正式写入需指向已核实目标库并单独核实具体数据操作；保留旧用户ID及密码，不删除历史作者。技术账号另计，虚构验收账号不得进入正式名单。学院不匹配时核查现有学院与新课表，不使用绕过参数强写。

原服务器备份保持只读；独立恢复与V3兼容克隆演练的路径、散列、计数和关联证据见[10月7日验收记录](上线收尾验收-20261007.md)。本机克隆成功不等于正式数据库已迁移。

2026-10-09对照文件夹内历史Excel：按现有六字段匹配规则，981条备份课程行未匹配，其中5条关联计划或评价。不得把旧Excel重新导入后当作完整历史、删除未匹配行或去重历史课程。原件路径、散列和只读对账见[历史留存对账](课表原件与历史留存对账-20261009.md)。

## 导入后检查

2026-10-08补充：预览中的“待核查”现在可展开原行明细或下载CSV清单，按原工作表及物理行号返回Excel核对。行号包含标题前和数据间空行；同一行可有多个核查原因。第0周的原日期不会自动挪为第一周，缺教师不会自动补姓名，没有有效周次的课程不能安排听课或评分。原文件、异常明细及经研究生院确认的处置记录应一并保存；出现问题先核实再导入，不通过修改目标第一周掩盖异常。

- 对应学期课程、评价及作者关联完整；新学期零评价。
- 全校课程总数与学院明细合计一致；学院领导和秘书仅见本院。
- MBA/工商管理学院分别存在；督导周次按9月14日第一周计算。
- 旧评价可读可打印、历史不可修改；切换查看没有改变全校当前学期。
- 原文件、导入预览与异常处置记录保留；禁止清表换学期。
